# CPD QuickMenu Generator

Генератор `quickmenu_data.json` для полицейского QuickMenu на RPM-ROLEPLAY (CPD).
Отделён в отдельный репозиторий из проекта [RPM-Police](https://github.com/kostikshvchuk-del/RPM-Police).

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Сам генератор (форма → JSON, копирование и скачивание `quickmenu_data.json`) |
| `fonts/minecraft-rus.woff2`, `.woff` | Шрифт **Minecraft Rus** — пиксельный шрифт в стиле Minecraft с полной поддержкой кириллицы |
| `cpd.ahk` | AutoHotkey-скрипт с горячими клавишами для QuickMenu |

## Пол персонажа

В форме есть переключатель **♂ Мужской / ♀ Женский**. Он меняет формы глаголов
в отыгровках (`достал` / `достала`, `схватился` / `схватилась` и т.д.), а также
`сотрудник` / `сотрудница` в текстах `/do`.

## Отыгровки

Обновлены процессуальные действия и дополнительные отыгровки:

- Удостоверение, Миранда, Обыск, Сфотографировать подозреваемого;
- Взять отпечатки пальцев, Арест;
- Выдать штраф (гражданину / машине);
- Поставить дверь на место, Мегафон;
- Посадить преступника в машину, Извлечь преступника из машины, Достать из закрытой машины.

Остальные пункты меню (вызовы, экспертиза, СЛР, разминирование и т.д.) сохранены;
в них также подставляются женские формы глаголов при выборе «Женский».

Отделов и подписи шерифа на сервере нет — эти поля из формы убраны, в удостоверении
остаются только ИФ, организация CPD, должность, дата выдачи и печать CPD.

## Как пользоваться

1. Заполнить имя, должность и дату выдачи.
2. Нажать **«Сгенерировать и скопировать»** — JSON попадёт в буфер обмена.
3. Вставить содержимое в файл `quickmenu_data.json` в папке с клиентом Minecraft
   (или нажать **«Скачать quickmenu_data.json»**).

## Шрифт

Шрифт подключён локально через `@font-face` (`fonts/minecraft-rus.woff2`), без внешних
CDN — страница работает офлайн и не зависит от сторонних сервисов.
